Mobile app prototype that helps teachers plan a lesson in about 10 minutes, using a structured canvas and suggestions from an AI copilot. Front end exported from Figma Make in React and TypeScript.

## About

Canvas Ágil organizes a lesson plan into blocks (opening hook, methodology, check for understanding and a fallback plan for when the internet goes down) and offers ready-made suggestions for each block. This repository stores the front end generated from the Figma Make prototype, kept as a visual reference and as a base for reusing components in other projects. There is no back end: screen data is mocked.

## Screens

| Screen | Component | Description |
| --- | --- | --- |
| Home | `HomeScreen` | Greeting, shortcut to a new plan and recent plans |
| Canvas | `CanvasEditor` | Block-based lesson plan editor |
| Copilot | `AIBottomSheet` | Bottom sheet with suggestions for the selected block |
| Library | `LibraryScreen` | Saved plans and templates |
| Community | `CommunityFeed` | Sharing between teachers |
| Schedule | `ScheduleManager` | Class schedule |
| Profile | `ProfileScreen` | User data and preferences |

The UI text is in Portuguese.

## Tech stack

- React 18 and TypeScript
- Vite 6 with `@vitejs/plugin-react-swc`
- shadcn/ui components on top of Radix UI
- CSS generated by Tailwind CSS 4 (already compiled into `src/index.css`)
- Lucide (icons), Recharts, React Hook Form, Sonner

## Running

Requirement: Node.js 18+.

```bash
git clone https://github.com/Luisr-nunes/CanvasAgil.git
cd "CanvasAgil/Canvas Ágil"
npm install
npm run dev      # http://localhost:3000
```

Production build: `npm run build` (output in `build/`).
